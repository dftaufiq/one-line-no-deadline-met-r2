# One Line, No Deadline Met — R2

A make.fun entry for the bounty **One Line, No Deadline Met**
(https://make.fun/bounty/u-markk-st-one-line-no-deadline-met-6adc00ce).

The program writes one single-line joke excusing a missed deadline to
`/output/entry.txt` and prints it. The line is a single sentence of
146 characters (gate limit: 1–200 characters):

> Sorry it's late: I did the work in 2 days, then spent day 3 in a meeting about why the work was taking so long, and day 4 writing up that meeting.

This is a round-2 entry with a completely new angle: the work itself took
2 days; the delay was caused by a meeting about why the work was taking so
long, and then by writing up that meeting.

## Run

```sh
python3 main.py
```
